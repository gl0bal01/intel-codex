## What makes it different

- **Copy-paste ready** — commands given for Windows, Linux and macOS
- **Heavily cross-referenced** — SOPs link to the procedures they depend on
- **Legal and ethical first** — every SOP states its boundaries before its techniques
- **OPSEC by default** — attribution and infrastructure hygiene built into each procedure
- **Practical over theoretical** — written from real operations, not literature reviews
- **Living documentation** — updated from field experience, with reusable templates
